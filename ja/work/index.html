WHAT WE DO / 私たちの仕事

モバイルゲーム開発に向き合い、アイデアをより良い体験へと磨き続ける。

モバイルプラットフォームを軸に、ゲームプレイ、体験、プロダクト品質を考え、常にターゲット市場のプレイヤーの感覚を大切にしています。

01 / MOBILE GAME R&D
開発の中心

アイデアと遊びから、モバイルに自然になじむ、完成度の高い体験へ。

検証、調整、改善を重ね、モバイルデバイスでもコア体験がわかりやすく、面白く伝わることを目指します。

すべての改善をプレイヤーの感覚に立ち返って考え、操作、テンポ、情報設計、プロダクト品質を整えます。

02 / FOCUS
大切にしていること

ゲームプレイ、体験、品質。

01

ゲームプレイ

コアとなるルールをわかりやすくし、長く楽しめる奥行きを持たせます。

02

体験

操作、テンポ、情報の伝わり方を整え、プレイヤーが自然にゲームへ入り込める状態をつくります。

03

品質

検証と改善を繰り返し、細部まで整えながら、プロダクト体験を完成へ近づけます。

03 / PROCESS
開発プロセス

すべての工程を、体験そのものに立ち返って考える。

01 / DEFINE

体験を定める

プレイヤーに何を感じてほしいかを捉えたうえで、表現の方法を考えます。

02 / PROTOTYPE

すばやく確かめる

アイデアを早い段階で、話し合い、実際に触れられる形にします。

03 / ITERATE

改善を重ねる

実際の体験から課題を見つけ、大切な細部を繰り返し磨きます。

04 / REFINE

一つの体験に仕上げる

ゲームプレイ、テンポ、情報設計をつなぎ、プロダクト全体の品質を高めます。

日本市場を中心に、より広い海外のプレイヤーへ。

ターゲットとなるプレイヤーの習慣を理解し、各市場の文化と表現を尊重します。

04 / COLLABORATION
協働のかたち

異なる専門性で、ともにつくる。

ゲーム開発には、異なる役割同士の理解が欠かせません。率直な対話とすばやいフィードバックを通じて、アイデアを話し合い、課題を見える状態にします。

共通の目標がチームの進む方向を整え、一人ひとりの専門性を協働の中で生かします。
